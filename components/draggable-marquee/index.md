Pass one set of items as children. It repeats them as often as the width needs, so there is
never a gap at the end, however wide the screen.

Grab it and throw: it coasts, slows by `friction`, then drifts on. Links and buttons inside
still work, since a drag never counts as a click. Arrow keys move it once focused.
