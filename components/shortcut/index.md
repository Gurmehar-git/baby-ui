title: Shortcut
description: Keyboard shortcut hint that reads correctly to screen readers.
component: shortcut
category: base
tags: [shortcut]
---

The glyphs are `aria-hidden` and a spoken form sits in visually hidden text, so a screen
reader says "Command then K" instead of attempting the symbols. Most shortcut hints on the
web are announced as gibberish for exactly this reason.

Rendered as `<kbd>`, which is what the element exists for.
