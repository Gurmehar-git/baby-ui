---
title: Asset Menu
description: "Composable context actions for copying, opening, and downloading reusable product assets."
component: asset-menu
category: advanced
tags: [asset, menu, copy, download]
---

Compose `AssetMenu` from its trigger, content, copy items, link items, previews, labels, and
separators. Copy results stay in application control through `onCopy`, so the caller can use its
existing toast or status system without coupling the component to one notification library.
