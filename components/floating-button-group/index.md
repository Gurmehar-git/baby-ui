title: Floating Button Group
description: "Soft buttons in a quiet tray with one shared highlight that glides to whichever button the pointer or keyboard is on."
component: floating-button-group
category: advanced
tags: [toolbar, actions, highlight]

Icon-only items and items with a `shortcut` get a tooltip. Pass `reserveLabels` when a label
changes in place (Share to Copied), so the button keeps its width.
