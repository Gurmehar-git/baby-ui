---
title: Toggle Group
description: Segmented set of toggles in single or multiple mode.
component: toggle-group
category: base
tags: [toggle, group]
---

Single mode lets you clear the active option by clicking it again. If clearing makes no
sense for your data -- a view mode always has to be *something* -- then this is a radio
group, not a toggle group, and the arrow-key behaviour users expect is different.

`variant="segmented"` slides one pill under the pressed item and follows resizes, for a
single-choice switch that reads as one control.
