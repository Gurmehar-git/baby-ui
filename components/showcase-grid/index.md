The "Every component, live" grid from this site's homepage. Panels flow in one 12-column
grid, so a row is any run of spans that adds to 12, and each row takes its tallest panel's
height.

Every panel draws a dot on its own four corners, so intersections line up at any breakpoint
without measuring. Put controls in `actions`: they sit top right and appear on hover or focus.
