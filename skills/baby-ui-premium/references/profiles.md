# Profiles: what weighs most per component type

| Type | Laws first | Must have |
| --- | --- | --- |
| Toggles (switch, checkbox, radio, toggle) | Fitts, feedback under 100ms | Thumb or mark travels on a spring curve; press squish; label toggles; 24px hit area; state shown by shape too |
| Text fields | Recognition, Postel | Visible label, inline validation on blur, error with cause and fix, calm focus edge |
| Select-likes and menus | Hick, Jakob | Origin-aware entrance, exit faster, roving focus, type-ahead, Escape returns focus, calm trigger |
| Dialogs and sheets | Jakob, forgiveness | Centred scale for modals, a sheet slides from its edge and back; focus trap and return; destructive actions confirm |
| Navigation | Jakob, Von Restorff | Current location marked; sliding highlight follows hover; no layout shift on open |
| Lists, tables, boards | Miller, Gestalt | Layout animation on reorder; drag 1:1 with a keyboard path; empty and loading states; tabular numbers |
| Charts | Data first, Gestalt | Entrance staggers once, never on every update; tooltips keyboard-reachable; legend; colour-blind-safe order; text summary |
| Carousels and galleries | Fitts, Doherty | Transforms only; drag 1:1 with momentum; settles on nearest; wheel and keys; live caption; reduced-motion jump |
| Upload and drop zones | Doherty, forgiveness | Drag-over cue within a frame; per-file progress, retry, remove that folds; keyboard browse; paste |
| Feedback (toast, alert, progress) | Doherty, peak-end | Enter and exit the same way; swipe to dismiss; polite live region; no colour-only state |
| Pricing and checkout | Hick, ethics, anchoring | One recommended plan; cycle switch glides; prices tabular and animate as numbers; no dark patterns |
| Onboarding and checklists | Goal gradient, Zeigarnik | Progress always visible; completed items check with a draw; collapse by grid rows |
| Agent and AI surfaces | Transparency, control | Streaming states, stop and retry, approvals that cannot be mis-clicked, state written out |
| Backgrounds and ambient art | Purpose, reduced motion | Pauses offscreen and when hidden; reduced motion stills it; never competes with content contrast |
| Marketing blocks | Von Restorff, aesthetic-usability | One focal point, one primary action; entrance once on scroll |
| OG and email templates | Hierarchy, restraint | One focal point, strict type ladder, safe contrast, renders in email clients and at 1200x630 |
