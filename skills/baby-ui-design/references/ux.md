# UX checks a page audit can verify

| Law or principle | Check on the page | Rule |
| --- | --- | --- |
| Fitts | Targets at least 24px (44px touch); primary action large and near its context | A11Y-002 |
| Hick | Choices per decision at most about 7; defaults preselected | UX-001 |
| Miller / chunking | Long lists grouped; 4 chunks for complex tasks | by hand |
| Jakob | Familiar patterns: close top-right, Escape closes, Enter submits | A11Y-003 |
| Doherty | Feedback within 100ms, response within 400ms; a loader beyond that | UX-003 |
| Von Restorff | One focal point per view | UX-001 |
| Gestalt | Related controls grouped by proximity; same look means same behaviour | by hand |
| Recognition over recall | Options visible, not memorised | by hand |
| Forgiveness | Undo or confirm for destructive actions | by hand |
| Goal gradient / Zeigarnik | Progress shown for multi-step tasks | by hand |
| Ethics | Accept and reject equally prominent; no confirmshaming; no pre-ticked consent | by hand |

## Friction matrix (for flows)

Score each friction point: users affected (%) x severity (1 to 10) / fix difficulty (1 to 3).
Fix the highest first. Extraneous load (decoration that doesn't inform, needless choices) is
always a finding.
