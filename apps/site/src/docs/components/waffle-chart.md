---
title: Waffle Chart
description: "A unit chart where every cell is one share of the whole; cells travel between parts when the data or legend changes."
component: waffle-chart
category: charts
tags: [waffle, unit chart, share, proportion]
---

Cells are allocated by largest remainder, so they always add up to the grid. New data and legend
toggles move as few cells as possible, and each part keeps its cells in order so paths never cross.
