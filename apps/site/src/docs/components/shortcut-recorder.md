---
title: Shortcut Recorder
description: "A field that records a keyboard shortcut and warns before taking a combination that is already bound or kept by the system."
component: shortcut-recorder
category: advanced
tags: [shortcut, hotkey, keyboard, settings]
---

Values are token strings like `mod+shift+k`, the same format the Shortcut component renders, so a
recorded binding displays correctly on every platform.
