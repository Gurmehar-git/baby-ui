---
title: Countdown
description: "Counts down to a launch, live event or deadline; digits roll each second and give way to a live label at zero."
component: countdown
category: advanced
tags: [countdown, timer, launch, event]
---

A target string without an offset is read as wall time in `timeZone` (or UTC), never the visitor's
own zone, so every visitor counts down to the same instant. It only ticks while visible.
